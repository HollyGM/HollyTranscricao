# Política de segurança

## Versões cobertas

Somente a série 2.x recebe correções de segurança.

## Como relatar

Não publique tokens, gravações, transcrições ou caminhos pessoais em uma issue pública. Use o recurso **Report a vulnerability** na aba Security do repositório. Inclua a versão, o sistema operacional, a forma de reprodução e o impacto observado.

## Dados processados

O aplicativo processa mídia localmente. Modelos podem ser baixados da internet na primeira utilização. O token do Hugging Face não é persistido pelo HollyTranscrição.
