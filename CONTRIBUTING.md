# Como contribuir

1. Abra uma issue descrevendo o problema ou melhoria.
2. Crie uma branch a partir de `main`.
3. Mantenha alterações pequenas e inclua testes quando houver mudança de comportamento.
4. Execute `ruff check hollytranscricao tests` e `pytest`.
5. Abra um pull request explicando o efeito para o usuário e os sistemas testados.

Nunca inclua gravações reais, transcrições privadas, tokens, modelos baixados, ambientes virtuais ou saídas de empacotamento no commit.
